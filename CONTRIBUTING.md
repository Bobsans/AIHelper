# Contributing to AIHelper

Thank you for helping make AIHelper more useful for AI-agent users and
CLI/DevOps developers.

## Choose the right channel

- Report reproducible bugs with the
  [bug report form](https://github.com/Bobsans/AIHelper/issues/new?template=bug_report.yml).
- Propose user-facing improvements with the
  [feature request form](https://github.com/Bobsans/AIHelper/issues/new?template=feature_request.yml).
- Do not report vulnerabilities in a public issue. Follow the
  [security policy](SECURITY.md) instead.
- Report community conduct incidents using the private contact in the
  [Code of Conduct](CODE_OF_CONDUCT.md).

Search existing issues before opening a new one. Include exact versions,
platform details, reproduction steps, and sanitized diagnostics when relevant.

## Contribute code or documentation

Read the [developer contribution guide](docs/developers/contributing.md) for
prerequisites, repository standards, required checks, compatibility rules, and
the expected development workflow.

Keep pull requests focused, explain why the change is needed, link related
issues, and list the exact validation performed. Behavior changes should include
success and failure coverage plus the corresponding user and agent
documentation.

By participating in this project, you agree to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).
